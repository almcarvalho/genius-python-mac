# Genius Python Mac

A modern reinterpretation of the classic **Genius / Simon Says** memory game developed using **Python**.

This project was created with a focus on:

- Game logic implementation
- Event-driven programming
- User interaction
- visual feedback
- Educational software development
- Python desktop application concepts

---

# Overview

The objective of this project is to recreate the classic memory challenge game where the computer must repeat increasingly complex sequences of colors generated by other computer (Macbook)

The project demonstrates how Python can be used to build interactive applications while exploring important concepts in:

- Software Engineering
- Game Development
- iOT
- Real-Time Event Processing
- Desktop Application Programming

# How the Game Works

1. The system generates a sequence.
2. The sequence is displayed to the player.
3. The computer must repeat the exact order.
4. Each round increases the sequence size.
5. The game ends when the computer makes a mistake.

The challenge progressively tests:

- Memory
- Pattern recognition
- Reaction time
